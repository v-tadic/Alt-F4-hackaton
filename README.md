# Habitly

Habitly je veb aplikacija koja omogućava korisnicima da prate svoje navike i postavljaju ciljeve u vidu streakova. Korisnici mogu kreirati navike koje žele da održe, pratiti svoj napredak i povećavati streak goal dok naviku ne ispune. Aplikacija takođe pruža mogućnost registracije i autentifikacije korisnika kako bi svaki korisnik imao svoj personalizovani nalog i podatke.

## Funkcionalnosti

- Registracija i prijava korisnika
- Kreiranje, izmena i brisanje navika
- Postavljanje i praćenje streak goal-ova
- Povećavanje streak goal-a dok navika nije ispunjena
- Pregled napretka korisnika

## Tehnologije

- Frontend: React.js, CSS, Vite
- Backend: Node.js, Express, SQLite
- API: REST
